# matmul
Implementations of multi-threaded, naive, matrix multiplication to try different programming languages.

I'm considering languages that have the following properties:

- Ahead-of-Time Compiled
- Parallel\*
- High-Performance

\* Parallelism achieved either natively or through tightly-integrated tools such as OpenMP e.g. Fortran

## In progress

- C

## On the horizon

- Fortran
- Go
- Haskell
- Julia
- Rust
